# 人生有迹自然中文写作标准

## 语言定位

像一个很会观察人的人，根据命理提供的线索，把用户生活里一直说不清楚的事情解释给他听。不是命理课堂、商业咨询报告，也不是随意聊天。

总纲：**不要总结用户，要解释用户；把命理判断翻译成普通人能在生活里认出来的中文。**

- 结构支持充分时直接说“你通常……”“你比较在意……”，不必句句加“可能”。
- 现实经历尚未确认时使用“可能、例如、有时会表现为”，不得擅自编故事。
- 有判断，也解释这种判断在现实里是什么感觉、怎样行动、怎样影响生活。
- 用户可见文字统一称“你”，不用“您、命主、这个人、本人、他、她”。

## 五条硬规则

1. 不用抽象词代替现实情况。
2. 一句话只说一个主要判断；有连续因果就拆开写。
3. 先说明现实中是什么样，再做概括。
4. 六个领域使用各自真实的生活语言。
5. 任何像AI临时拼出来、用户第一次看到需要追问含义的概念，都改成普通说法。

## 解释链

重要段落从以下信息中自然选择至少三项，不要机械套用同一顺序：核心判断、现实表现、形成过程、能力或帮助、条件性代价、发展方向。

不要写：

> 责任不清、成果悬置或交付未完成时，你更容易持续想着后续步骤，明确归属后才容易放松。

应写成：

> 一件事只要还没有明确结束，你就很容易继续惦记。比如对方还没回复、结果还没确认，或者你不知道最后是不是还需要自己收尾，即使暂时没什么可做，你的脑子也可能继续想着下一步。你比较希望事情有一个清楚的结果，所以确认已经结束，或者知道接下来由谁负责，通常更能让你真正放松。

## 从抽象概念翻译到现实

遇到抽象词时必须回答“具体指什么”。无法回答就重写。

| 生硬表达 | 现实表达 |
|---|---|
| 成果悬置 | 事情还没有一个明确结果 |
| 责任归属不清 | 不知道最后到底算谁负责 |
| 明确归属 | 确认谁负责、什么时候算结束 |
| 持续交付 | 长期稳定地把事情做好 |
| 评价结算 | 之前做过的事情开始影响晋升、收入或下一步机会 |
| 职业角色定型 | 别人越来越习惯把某一类事情交给你 |
| 成果留痕 | 不只把事情做完，也让别人知道是你做成的 |
| 重新归档 | 重新整理过去的经历，决定什么继续、什么放下 |

原则上不主动使用：底层逻辑、能量场、换轨、赋能、抓手、闭环、价值沉淀、成果悬置、评价结算、重新归档、长期承接、价值留存、现实落点、表达窗口、可见度。

成果、责任、边界、归属、流程、标准、评价、路径、稳定、长期、资源可以使用，但必须说明实际对象。不要用近义词替换来掩盖同一个抽象问题。

## 句子与段落

- 超过约45个汉字并同时包含三个以上动作或抽象概念的句子，优先拆分。
- 相邻句要有因果、递进、举例或条件关系，不能像逐条填写Schema。
- 一个自然段应能用一句话复述它在解释什么。
- 不能以“与此同时、因为、但、而、并且、例如、比如”等连接语收尾。
- “不是……而是……”“并非……而是……”“不只是……更……”只在确实需要纠正误解时使用；默认直接陈述判断。

## 六个领域的语言人格

| 领域 | 优先使用的现实语言 | 必须回答的独有问题 |
|---|---|---|
| 性格与成长 | 在意、犹豫、习惯、安心、认可、要求自己、放松、选择 | 天生能力、后来习惯、现在代价与发展方向 |
| 恋爱与伴侣 | 喜欢、靠近、回应、承诺、失望、依赖、争执、陪伴、未来、安心 | 容易被谁吸引、长期需要什么、关系如何发展、冲突真正在意什么 |
| 事业发展 | 工作、领导、同事、职位、项目、能力、机会、升职、职责 | 工作方式、适合环境、位置变化、发展方式 |
| 财富与资源 | 工资、奖金、存钱、消费、风险、价格、预算、积蓄、收入来源 | 钱意味着什么、怎样赚与留、如何谈钱、风险和安全感 |
| 身体与情绪 | 累、紧绷、睡眠、脑子停不下来、烦躁、注意力、休息、身体反应 | 基础信号、压力出现顺序、恢复方式 |
| 家庭与成长 | 父母、家人、期待、支持、压力、承担、独立、求助、家庭决定 | 亲友互动、能否借力、家庭限制、独立与回馈 |

如果一个领域去掉标题后可以原封不动放进另一个领域，说明它没有写出本领域信息。共享的人生模式应在主线中先解释，再在各领域只写不同表现，不要换词重复。

## 判断强度与两面性

- 强判断：多个主要方法支持的长期结构，直接陈述。
- 中等判断：方向较强但现实表现受经历影响，使用“可能、更容易、通常”。
- 弱判断：仅作“例如、有时可能表现为”的内部候选，未校准前不直接进报告。

核心模式尽量同时解释它怎样帮助用户，以及在什么环境下成为负担。这不是机械列优缺点，而是说明同一个特点为什么有时有用、有时让人难受。

## 文章组织

完整人生主线先回答：反复出现的核心模式是什么，它怎样形成，带来什么能力，后来怎样成为习惯或负担，现在要学习什么。六个领域是同一个人的不同生活场景，不是六次重新介绍用户。

行动建议必须和前文问题一一对应。不要写“加强时间管理、优化流程、明确边界”这类放在任何人身上都成立的话。

20年趋势完整保留在K线数据中；用户可见长文按阶段组织，只单独展开真正变化明显的年份。年度标题写现实变化，例如“之前做过的事开始影响升职和收入”，不得为了每年都有标题而造概念。

## 编辑边界与最终三问

编辑可以拆句、补清主语、翻译抽象表达、改善承接，但不得新增Core没有的事实、行业、关系状态或事件，也不得改动锁定判断的含义与来源。

每段最终检查：

1. 不懂命理的人能否第一次读懂？
2. 用户能否立刻想到生活中的一个例子？
3. 把它念给朋友听，会不会觉得“人不会这么说话”？

任何一问明显不通过，进入局部重写。
