# 报告事实提纲规范

## 目录

1. 选择原则
2. 完整人生主线
3. 六个现实领域
4. 当前问题
5. 具体名词
6. 校准

## 1. 选择原则

先锁定判断，再写文章。每个章节保存判断编号、形成链、联动链、可以使用的现实例子、禁止外推和证据缺口。选择完成后必须运行实体化脚本，将Core中的现实结论、实体证据、形成链、联动链、盲派现实取象、根苗花果领域生命周期、候选关系、校准变化、来源类型与哈希原样写入提纲。不得把Core技术短语复制成提纲结论，也不得让写作模型只凭判断编号猜测内容。

## 2. 完整人生主线

保持全盘视角，至少覆盖核心性格、行为方式、家庭教育、资源起点、事业财富、关系方式、当前阶段和长期发展。关注方向不能改变材料比例。

## 3. 六个现实领域

每个领域至少准备特征、行为、形成、经历或环境、重复挑战、阶段变化和应对条件。正常章节至少使用6个有效判断，其中至少4个必须是本领域专属判断，并至少有两个本领域机制。校准后不足时严格继承确定性选材给出的 `shortened`、`minimal` 或 `evidence_gap`，缩短对应章节而不凑字。共享人生主线判断最多占30%，同一判断最多进入两个领域。不得把事业材料换词用于其他领域。

为完整人生主线最多选择2个重点判断，为当前问题最多选择1个，每个现实领域最多选择1个；没有合适判断时允许为空。重点判断只用于生成用户可见的完整结论句，不选择证据说明、例子、免责声明、连接语或行动清单。

完整人生主线和六个领域中，命盘长期判断与岁运阶段判断合计至少占八成，用户事实修正最多一条。这个比例由脚本计算，不能手填。

## 4. 当前问题

单独整理用户当前问题、主要判断、成立条件、反例、当前阶段、未来两三年和行动方向。这里可以提高用户关注方向的权重。

## 5. 具体名词

Core候选池是开放的。只选择证据最强的一至三个例子，保留必要替代方向，不把候选池全部列给用户。准确区分工作方式、组织、行业、部门、岗位与收入机制。

## 6. 校准

确认项作为主要表现；未被选择但能够共存的支持项用于刻画人物另一面；条件项必须说明阶段或情境；降低优先项只能弱表达；未验证项只在确有多方法支持时作为候选；排除项禁止进入提纲。用户原始答案和内部校准栏目不进入最终报告。

选择A不等于其他候选自动排除。只有Core候选关系已标记为同一时间、口径和比较轴下真正互斥，才可禁止未选项进入报告。
