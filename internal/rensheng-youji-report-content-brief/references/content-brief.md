# 报告事实提纲规范

## 目录

1. 选择原则
2. 完整人生主线
3. 六个现实领域
4. 当前问题
5. 具体名词
6. 校准

## 1. 选择原则

先锁定判断，再写文章。每个章节保存判断编号、形成链、联动链、可以使用的现实例子、禁止外推和证据缺口。不得把Core技术短语复制成提纲结论。

## 2. 完整人生主线

保持全盘视角，至少覆盖核心性格、行为方式、家庭教育、资源起点、事业财富、关系方式、当前阶段和长期发展。关注方向不能改变材料比例。

## 3. 六个现实领域

每个领域至少准备特征、行为、形成、经历或环境、重复挑战、阶段变化和应对条件。每个领域至少使用4个有效判断，建议6—10个；不得把事业材料换词用于其他领域。

## 4. 当前问题

单独整理用户当前问题、主要判断、成立条件、反例、当前阶段、未来两三年和行动方向。这里可以提高用户关注方向的权重。

## 5. 具体名词

Core候选池是开放的。只选择证据最强的一至三个例子，保留必要替代方向，不把候选池全部列给用户。准确区分工作方式、组织、行业、部门、岗位与收入机制。

## 6. 校准

确认项可以直接使用；部分支持项使用条件式表达；未验证项只在确有多方法支持时作为候选；排除项禁止进入提纲。用户原始答案和校准状态不进入最终报告。
