# 免费卡片确定性内容提取规则

## 目录

1. 输入优先级
2. 命局分析
3. 当前课题
4. 完整版提示
5. 压缩与去重

## 1. 输入优先级

`build_card_content.py` 按以下来源边界取材：

- 四柱、命理结构和人生主线只读校准前冻结Baseline；
- 当前课题优先读取校准后的 `resolved-report-sources.json`，再读取校准后Core中仍未被排除的判断；
- 身份与出生时间地点只读确定性 `profile.json`。

不得让AI重新选择卡片文字，不得使用被列入 `not_inferable_register`、被用户否定或仍是 `calibration_pending` 的内容作为卡片主结论。已由校准确认或转为条件判断的待校准候选，只有进入确定性选材后才能成为当前课题。

## 2. 命局分析

### `structure_text`

程序优先读取Baseline中已经完成综合的 `natal_portrait`；缺失时才退回 `method_synthesis` 的摘要。内容目标为70—120个汉字，结构为：

> 核心命理结构 → 能力如何形成 → 容易卡住的环节 → 现实中的常见表现

如果Baseline摘要包含必要命理依据，保留并立刻翻译成白话；不要让卡片层自行拼接月令、根透、十神链等字段重新推命。

### `life_theme_text`

程序读取Baseline的 `portrait_thesis`，不使用五题答案改写。内容目标为45—90个汉字，回答：这个人反复需要把什么能力，经过什么现实考验，转成什么结果？不要只复制事业章节。

### 时柱检查

读取Baseline边界审计。若入选结论高度依赖时柱，程序写入 `time_dependency_note`；若时柱改变会影响能力落点或后期成果，也应在内部 `basis` 中保留。

## 3. 当前课题

当前课题不再由卡片AI重新打分。程序直接读取校准后确定性选材的 `current_question.mandatory_claim_ids` 或 `claim_ids`；若没有校准后选材，才回退到Core中当前阶段来源。被排除、证据较弱和未确认的待校准判断一律跳过。

输出：

- `domain`：一个领域；
- `title`：由领域映射为简短问题标题；
- `body`：使用入选判断的 `plain_claim`；
- `example`：使用该判断已审核的 `allowed_examples`，没有时使用中性观察提示；
- `basis`：内部证据，不在卡面展示；
- `confidence`：高、中或待验证。

避免“你现在面临选择”“你需要相信自己”等泛化句。优先写成“已经准备了很久，但真正要交付时仍想再等等”这类可辨认场景。

## 4. 完整版提示

- 标题：`想看更长的人生轨迹？`
- 正文：`完整版将展开更长时间范围、逐年伏笔与事业、财务、关系之间的传导。`

## 5. 压缩与去重

- 卡面只保留两段命局分析和一项当前课题。
- 同一个结论不得同时出现在结构、人生主线和当前课题中。
- 命局分析说长期结构；当前课题说当前阶段的具体矛盾。
- 删除无法由 Core 证据支持的漂亮话、鼓励话和神秘化表达。
