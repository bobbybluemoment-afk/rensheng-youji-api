# 人生有迹免费卡片输出层

## 定位

只消费已校验的 Core 完整分析母稿。不得绕过 Core 使用旧版日柱角色、固定文案或旧 K 线分数，不得重新排盘。

本层决定免费卡片展示什么，但不修改 Core 结论。输出必须符合 [free-card-output.schema.json](schemas/free-card-output.schema.json)，供后续 Python 或网页渲染器直接使用。

## 流程

1. 确认 `analysis_bundle.analysis_meta.status` 为 `complete`，目标年份连续且恰好20年。
2. 读取 [content-selection.md](references/content-selection.md)，提取命局分析、当前课题和完整版提示。
3. 读取 [visual-algorithm.md](references/visual-algorithm.md)，先把 Core 语义整理为 `visual-signals.json`。必须明确窗口起点状态和20个年度信号；不得让脚本从自然语言关键词猜分。
4. 校验视觉信号：

```bash
python3 scripts/validate_visual_signals.py visual-signals.json
```

5. 运行确定性趋势映射：

```bash
python3 scripts/build_visual_series.py visual-signals.json \
  --output visual-series.json
```

6. 将 `visual-series.json` 原样放入 `trend_panel`。不得手改起点、OHLC、事业层级、元宝数量或桃花年份。
7. 组合完整 `free-card-output.json`。
8. 运行 `python3 scripts/validate_free_card_output.py free-card-output.json`。

只有校验通过后才能交给绘图层。

## 展示结构

按以下顺序输出：

1. `identity`：姓名可空、性别、出生时间地点、时间口径；
2. `mingju_analysis`：四柱、核心结构、人生主线；
3. `trend_panel`：20年人生K线、事业、财运和重点桃花；
4. `current_issue`：当前最可能遇到的一项具体课题；
5. `full_report_hint`：更长时间和逐年解释的提示；
6. `disclaimers`：趋势指数与传统文化体验边界。

不要恢复“初始天赋”“XX型选手”“单列日柱”“主线任务”等旧栏目。人生主线合并写入命局分析。

## 文字规则

- `structure_text` 保留必要命理依据，再紧接现实解释；不能只剩性格或事业。
- `life_theme_text` 提炼反复出现的能力、矛盾与现实传导，不能写成口号。
- 两段都必须受到时柱证据影响；如果结论高度依赖时柱，填写 `time_dependency_note`。
- 当前课题只能选择一个主领域，可从工作、财务、感情、家庭、学习、迁移或自我成长中选择。
- 当前课题综合原局主轴、所在大运、当前年及前后两年、年龄和可用现实资料；年龄只能缩小场景，不能直接决定答案。
- 标题不超过20个汉字，正文使用“可能、例如、如果”等保留余地的表达，但必须给出具体生活场景。
- 避免“换轨、抓手、赋能、内耗、能量场、人生副本、显化”等黑话。
- 不许承诺事件发生，不把变化强度写成吉凶，不把财运指数写成真实金额。

## 图形规则

- 时间窗口固定为当前年前5年、当前年、未来14年。
- 起点表示窗口第一年开始时已经带入的现实积累，不是人人固定为同一数值。优先使用已确认现实事实，其次看此前大运积累、原局承载条件，年龄只作很小修正。
- 没有学历、职业、收入、资产或关系状态等现实资料时，使用 `birth_only` 模式并向中性区间收缩；不得把命理候选冒充真实履历、职位或资产。
- 人生K线年度开盘值承接上一年收盘值，保证连续；实体等宽、间距一致，绘图层不得加入五年分区底色或额外收盘连线。
- 人生K线由大运 `stage_target_shift` 给出阶段目标、流年逐年执行；年龄和当前位置只作轻度正向阻尼，不得直接制造下降，`durable_shift` 只修正能够长期留下的变化。
- 人生K线分别表达机会、代价、兑现和折返程度；“混合”不自动上涨或下跌。普通年收盘变化不超过3点，结构转换不超过4点，只有现实事实确认的重大年份可到5点。`birth_only` 单年跨度不超过16点，现实校准重大年份不超过18点。短实体长影线只用于明确反复的少数年份，不得成为默认形态。
- 事业以逐年断开的空心台阶展示，名称固定为“步步高升”；小人样式由绘图层决定。
- 事业台阶表示相对角色、责任、平台和可见成果，不等于真实职级或工资。学习、迁移和高变化只有形成落地成果时才上升；年龄与当前位置只在已经确认上涨后轻度修正幅度，不制造方向。
- 财运只用金元宝堆积表达相对资源承载水平，元宝跨年连续排布，不画顶部轮廓线。
- 财运表示可积累、可支配的财务资源，不等于净资产；事业成果允许跨年传导，投入、家庭责任和资源重组可使元宝暂时减少。内部元宝等级不变，绘图显示量统一使用 `2 × ingot_count - 2`，采用小尺寸连续元宝堆积，不画顶部线。
- 桃花只标记“关系进入或发展机会”证据达到门槛的年份；单纯冲突、结束或关系领域被激活不能画花。不设20年总数量上限，改用相邻年份择强保持稀疏；弱、中、强机会分别画1、3、5或7朵。所有桃花使用粉色，包括当前年，不改为金色。
- 当前年份仅在年份文字与人生K线主体中使用金色高亮。

## 证据与缺失

将 Core 的 `finding`、大运主题和年度激活字段写入内部 `basis`，但绘图层不展示。

若关系、财富或事业证据不足，保留相应趋势结构并使用低置信度或平缓数值；不使用社会刻板印象填补，桃花年份可以全部留白。

## 完成检查

- 四柱与 Core 完全一致且顺序为年、月、日、时；
- 命局分析包含命理结构与人生主线，不包含旧角色标签；
- 20个年份连续，当前年位置为第6个；
- K线连续、影线跨度合规；
- 事业、财运、桃花均来自统一脚本；
- 当前课题具体且不是仅按年龄生成；
- 语言简短、普通、可读；
- 输出校验通过。
