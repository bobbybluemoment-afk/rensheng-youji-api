# 人生有迹免费卡片绘图层

## 定位

只消费已校验的 `free-card-output.json`。不得重新排盘、重算趋势、增删桃花年份、修改当前课题或从自然语言猜测数值。

## 流程

1. 确认输入来自 `rensheng-youji-free-card-output`，包含连续20年且当前年位于第6个位置。
2. 从仓库根目录运行：

```bash
python scripts/generate_card.py --input free-card-output.json --output rensheng-youji-card.png
```

3. 检查PNG存在且尺寸为1242×1660。
4. 目视检查文字溢出、K线遮挡、元宝截断、桃花重叠和当前课题换行。

## 固定视觉

- 页面顺序固定为命局分析、20年行情盘、当前课题。
- 命局分析展示四柱、必要命理结构和人生主线；不显示“年柱/月柱/日柱/时柱”、日柱角色、初始天赋或单列主线任务。
- K线实体等宽、间距一致、逐年连续；纵轴依据实际高低值按5点刻度自动缩放，至少保留20点显示区间；不画五年背景色块。
- 当前年只在年份文字和K线主体使用金色，不增加“你在这里”或贯穿图表的金色背景带。
- 事业名称固定为“步步高升”，逐年画断开的空心台阶；当前年放简笔小人。
- 财运使用 `display_ingot_count` 决定堆积高度，以较小金元宝连续铺满年度区域，不留明显年度空隙，不画顶部轮廓线。
- 桃花只在 `highlight=true` 的年份画粉色枝花，朵数只能为1、3、5或7；当前年也保持粉色。
- 当前课题正文必须正常换行，标题使用强调色。

颜色、尺寸与网页复用约定见 [render-contract.md](references/render-contract.md)。

## 边界

- 只输出图像，不把趋势指数解释为真实职位、金额、对象数量或事件保证。
- 输入字段不合规时直接失败，不自行补值。
- 网页端应复用 [render-contract.md](references/render-contract.md) 的坐标、颜色和图形规则；若实现方式不同，也不得修改数据含义与视觉映射。

## 完成检查

- PNG尺寸为1242×1660；
- 四柱顺序与输入一致；
- 20根K线、20个事业台阶完整；
- 当前年只出现一次金色年份高亮；
- 元宝使用连续堆积画法与新显示尺度；
- 桃花朵数与输入一致；
- 卡片没有文字截断或大段无意义空白。
