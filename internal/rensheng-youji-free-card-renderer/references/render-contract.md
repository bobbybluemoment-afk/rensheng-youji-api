# 免费卡片绘图约定

## 画布与字体

- 画布：1242×1660，接近3:4竖版。
- 正文与标题：仓库内置 Noto Sans CJK SC，避免依赖设备默认中文字体。
- Python/Pillow 直接生成PNG；网页版按相同坐标、颜色和数据映射实现响应式画布。

## 色彩

| 角色 | 色值 |
|---|---|
| 背景 | `#F6F0E5` |
| 正文 | `#303638` |
| 主色 | `#315B63` |
| 暖色K线 | `#B96545` |
| 当前年金色 | `#B89552` |
| 桃花粉 | `#D77F91` |
| 元宝金 | `#F4C542` |

## 数据到图形

- K线：直接读取 `open/close/high/low`，不得平滑或再打分。
- 事业：直接读取 `career.level`，只做纵坐标映射。
- 财运：读取 `wealth.display_ingot_count` 形成连续元宝堆；不再使用原始 `ingot_count` 决定画面密度。
- 桃花：读取 `highlight` 与 `blossoms`；无机会年份完全留白。

## 网页复用

网页端复用同一坐标、色值与图形语义。允许响应式缩放整个画布，不允许分别重写K线、事业、财运或桃花算法。
