# 大运主题分析规范

## 一、核心原则

大运是十年舞台和主题，不是十个年份分数的平均值。它改变命主在一个阶段更容易遇到的资源、关系、责任、竞争、身份与环境，也改变原局某些结构是否有条件发挥。

分析每步大运时，必须把大运干支及其藏干完整放回原局，不能只看大运天干或只看地支刑冲合化。

## 二、主题形成

依次判断：

1. 大运天干相对日主的十神及其在原局中的来源与去向；
2. 大运地支的主气、中气、余气及全部十神；
3. 大运是否为原局某十神提供根、源、透出、制衡或通关；
4. 大运与原局形成的合冲刑害破是否真正改变结构；
5. 月令和全局气势是否允许合化、成局或专旺；
6. 哪些原局潜在关系被推到台前；
7. 主题主要落在身份、资源、关系、作品、规则还是迁移环境；
8. 主题中的机会、成本和必要能力分别是什么。

## 三、人与社会阶段

同一步十神大运落在不同年龄，现实表现可能不同。例如同为财运，青年阶段可能表现为初次独立挣钱、恋爱与消费责任，中年阶段可能表现为经营、资产、团队成本或家庭财务。

因此每步大运必须与命主当时的年龄、教育或职业阶段、家庭责任和可用资源交叉。社会阶段只决定表现候选，不改变命盘结构。

## 四、前后大运承接

每步大运至少说明：

- 上一步留下的技能、关系、资产、身份或未完成问题；
- 本步大运接手了什么；
- 前三年如何进入主题，中段如何展开，后段如何收束或转向；
- 哪些成果会进入下一步大运；
- 哪些问题若未处理，会在后续换一种形式重复。

换运不是某一天彻底翻转。允许出现过渡带，特别是在交运前后和现实项目跨年时。

## 五、激活键

为每步大运建立 `activation_keys`：

- 大运天干重复或被合、克、生；
- 大运地支重复、冲、合、刑、害、破；
- 大运藏干在流年透出；
- 流年使大运与原局形成三合、三会、拱合或通关条件；
- 流年为相关十神补根、去根、开库或改变可见度；
- 现实事件提供对应入口，如毕业、入职、迁移、婚育、创业、照护。

## 六、大运输出

每步大运输出：

- `theme_statement`：一句白话主题；
- `structural_mechanism`：原局与大运如何形成主题；
- `opportunities` 与 `costs`；
- `required_capabilities`：需要培养的现实能力；
- `activated_domains` 与跨域路径；
- `activation_keys`；
- `entry_phase`、`middle_phase`、`exit_phase`；
- `continuity_from_previous` 与 `seed_for_next`；
- `confidence`、替代解释及出生时间依赖。
