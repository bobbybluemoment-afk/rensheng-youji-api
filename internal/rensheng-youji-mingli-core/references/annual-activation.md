# 流年执行与连续性规范

## 一、核心公式

流年分析采用以下因果链：

> 大运主题 → 流年触发 → 原局反应 → 人的选择与行为 → 社会反馈 → 阶段结果 → 下一年伏笔

流年不是独立的好坏标签，也不是看到某个冲合就直接下结论。

## 二、年度分析顺序

1. 读取该年所处的大运及大运阶段；
2. 列出流年天干、地支、主气、中气、余气及全部十神；
3. 检查流年是否重复、透出或引动大运干支与藏干；
4. 检查流年、大运、原局三层形成的新关系；
5. 判断反应改变的是根、透、源、通关、制衡、库或宫位；
6. 识别最先被激活的现实领域；
7. 描述命主可能采取的行动与外部环境反馈；
8. 说明机会、代价、变化强度与不确定性；
9. 连接上一年遗留与下一年伏笔。

## 三、变化强度与结果方向分开

变化强度表示一年内状态、环境或决策的变化范围，不表示吉凶。结果方向需要另行分析。

- 高变化 + 正向：机会大，同时要求快速适应；
- 高变化 + 混合：得失并存，关键在选择与承接能力；
- 高变化 + 负担：责任或冲突集中，但可能为后续重组创造条件；
- 低变化 + 正向：稳定积累；
- 低变化 + 停滞：外部变化少，内部准备或约束较多。

不得为制造视觉波动而夸大年度跨度。年度状态应受上一年、当前大运基线和现实惯性约束。

## 四、年度连续性

对相邻年份必须记录四项：

- `carry_in`：从上一年带入的技能、关系、资产、身份、压力或未完成事项；
- `execution`：本年如何使用、放大、修正或消化；
- `carry_out`：本年可沉淀的结果；
- `seed_for_next`：下一年可能继续发展的伏笔。

连续性来自人的记忆、能力、合同、关系、资产、家庭责任与社会位置。命理变化只能通过这些现实载体发生，不应呈现“上一秒好运、下一秒厄运”的机械跳变。

## 五、三层时间尺度

- **十年层**：大运主题与结构条件；
- **年度层**：主题被执行、转折或暂缓；
- **月度层**：年度事件的窗口、节奏和局部反馈。

月运不得推翻年度与大运主轴，只用于观察阶段内的时点和节奏。没有可靠月度计算时，不得补写具体月份。

## 六、年度语义输出

内部核心应输出完整语义，不直接决定 K 线 OHLC 或视觉样式。每年建议包含：

- `year_theme`；
- `luck_theme_link`；
- `activation_mechanisms`；
- `natal_reactions`；
- `change_intensity`：低 / 中 / 高；
- `direction`：支持 / 混合 / 承压 / 整理；
- `domain_impacts`；
- `domain_connections`；
- `human_actions`；
- `social_feedback`；
- `carry_in`、`carry_out`、`seed_for_next`；
- `confidence`、`alternatives`、`validation`。

下游卡片或网页可据此映射为 K 线、事业台阶、财富堆积、桃花机会等视觉，但不得反向修改母分析。

## 七、避免误判

- 不因冲而自动给低分；冲也可能推动迁移、断舍离、岗位转换或堵点打开。
- 不因合而自动给高分；合也可能带来牵绊、责任、资源锁定或边界模糊。
- 不因同一十神重复就认定同一事件；现实入口与人生阶段不同，表现会不同。
- 不把单年振幅当作财富、婚恋、健康或事件概率。
- 不输出“必然结婚、必然失业、一定发财”等断言。
