# 资源关系与领域联动规范

## 一、人与资源的关系

资源分析必须同时写明来源、获取条件、隐性代价、保存方式、交换方式、放大路径、流失风险、时运激活和跨领域去向。不得把印只写成学习、财只写成钱、官杀只写成事业、比劫只写成竞争、食伤只写成表达。

家庭资源尤其要区分“得到什么”与“因此承担什么”；关系资源要区分情绪支持、信息连接、合作机会和利益分配；能力资源必须说明如何经过作品、资格、岗位或项目转成现实回报。

资源不只指钱。至少分析六类资源：

- 物质资源：收入、资产、现金流、物品与空间；
- 制度资源：学历、证书、职位、平台、规则与公共系统；
- 人际资源：家人、同辈、伴侣、客户、上级、合作伙伴；
- 能力资源：知识、技能、经验、作品、表达与判断力；
- 身体与时间资源：精力、恢复能力、可支配时间；
- 心理资源：安全感、自我效能、边界和承受不确定性的能力。

对每类资源回答：如何获得、如何保存、如何交换、如何放大、如何失去，以及在压力下会采取什么策略。

## 二、十神资源链

十神之间的生克可转译为资源流动，但不得机械等同。例如：

- 印生身：知识、制度或照护如何成为能力与底气；
- 身生食伤：能力如何变成表达、作品和市场供给；
- 食伤生财：输出如何形成交换、收入或客户价值；
- 财生官杀：资源如何带来责任、规则、身份或风险；
- 官杀生印：压力与制度如何转化为资质、方法和保护；
- 比劫夺财或帮身：同辈既可能分配资源，也可能共同承担与放大资源。

必须结合旺衰、根透、制化和时运判断链条是否真的可运行。

## 三、领域连接图

现实领域包括但不限于：事业、财富、学习、关系、家庭、居住迁移、健康与自我成长。每个结论都应检查是否存在跨领域传导。

用以下字段记录：

- `source_domain`：起点；
- `trigger`：时运或现实触发；
- `mechanism`：人的行为与社会反馈；
- `target_domain`：结果落点；
- `lag`：即时、数月、跨年或长期；
- `amplifiers`：放大条件；
- `buffers`：缓冲条件；
- `evidence`：命理与现实证据。

## 四、常见联动路径

以下仅是路径模板，不是固定结论：

- 学习/证书 → 岗位门槛 → 收入变化；
- 事业曝光 → 新人脉 → 合作或关系机会；
- 亲密关系 → 城市/住房选择 → 职业调整；
- 家庭责任 → 时间减少 → 财务保守与职业稳定偏好；
- 作品输出 → 市场反馈 → 自信与定价能力；
- 健康与精力 → 执行效率 → 事业和关系耐心；
- 合伙关系 → 资源放大 → 分配与边界问题。

## 五、领域强弱不等于事件好坏

某领域被强烈激活，只表示它成为生活重点，不等于结果必然正面或负面。要继续区分：

- 机会增加还是责任增加；
- 流量增加还是可沉淀成果增加；
- 收入增加还是现金流波动增加；
- 关系机会增加还是边界考验增加；
- 事业上升是否以健康、家庭或自由为代价。

## 六、完整输出

最终母分析需同时给出：

- 每个领域的结构基础；
- 当前大运的领域排序；
- 年度激活与跨域传导；
- 可能的正向循环、消耗循环；
- 可验证迹象和替代解释。
