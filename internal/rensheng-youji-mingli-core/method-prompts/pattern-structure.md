# 格局法｜pattern_structure

只回答“全盘围绕什么任务组织、怎样算成立、哪里容易破坏”。

1. 以月令和透干为入口，检查主导关系、相神救应、顺逆配合、清纯混杂。
2. 把扶抑、病药、通关、根透、制化作为本方法内部机制，不能拆成额外方法票数。
3. 先判断结构怎样获得价值、责任或社会位置，再推现实中的规则密度、专业门槛、组织依赖和成果方式。
4. 必须写出成格或成局所需条件，以及被合冲、失根、过度或时运改变时的反向表现。
5. 不得把某个十神直接翻译成固定职业、收入或家庭事实。
