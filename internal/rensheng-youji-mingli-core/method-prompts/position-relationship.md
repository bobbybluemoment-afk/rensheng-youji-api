# 宫位、六亲与位置关系｜position_relationship

这是部分独立方法，只回答“命主处在什么位置、资源从哪里接入、与家庭和关系对象怎样形成位置互动”。

1. 同时看四柱位置、干支连接、远近内外和被时运引动的接口，不把一个宫位固定等于一个人的全部情况。
2. 重点检查家庭资源、父母亲友互动、能否借力、独立与回馈，以及关系中的需要、吸引和边界。
3. 必须实际检查 `love_partner`；单人命盘只能分析命主一侧，不能描述具体伴侣事实。
4. 位置关系与主要方法共享底层事实，不能独立抬高结构置信度。
5. 至少形成一条技术结论和一条现实候选，不为数量扩写。
