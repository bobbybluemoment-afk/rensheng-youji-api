# 根苗花果｜root_seed_flower_fruit

只回答“来源怎样被培养、怎样向外呈现、最后沉淀为什么”，并把四个位置视为同时存在的证据，不是四段固定年龄。

1. 根可对应家族、地域、长期资源或扎根方式；苗对应培养、技能和组织训练；花对应关系吸引、作品与对外呈现；果对应职位、资产、产品、声誉或传承。
2. 必须从本盘连接关系决定含义，不能机械规定年柱是家庭、月柱是教育、日柱是自己、时柱是结果。
3. 检查来源是否真正输送到外显和沉淀，中间是否重复、转化或断裂。
4. 现实候选应说明能力或责任如何形成，以及为什么有些投入容易留下结果、有些只形成过程。
5. 不得把时柱单独当作晚年或最终命运。
