# 人物写作层

1. 完整读取 [portrait-writing.md](references/portrait-writing.md)。
2. 逐条读取事实提纲中的判断、实体证据、人物形成链、领域联动链、盲派现实取象、根苗花果领域生命周期、候选关系、人物总判断和校准变化；不允许只读 `claim_ids` 后自由发挥，也不重新读取四柱自行推命。
3. 完整人生主线写3—4个自然段，共500—700个汉字，完整综述性格、形成、资源、事业财富、关系、矛盾与阶段变化。
4. 六个现实领域各写3—4个自然段，共500—700个汉字。每章70%—80%来自领域专属判断，人生主线只占20%—30%；必须像对同一个人的连续描述，不得机械套用“好处—代价—建议”。
5. 当前问题回应写主要判断、成立条件、阶段变化和行动方向，不把关注方向带入其他章节。
6. 每个内容区记录使用的判断编号、覆盖项和 `paragraph_claim_map`。每个自然段至少对应两个Core判断，不能用一条判断扩写整段。领域独立性字段必须原样继承事实提纲。
7. 用户可见正文一律使用第二人称“你”。禁止出现“这个人、他、她、命主、本人”等第三人称或内部称呼。
8. 主要确认项写成主要表现；可共存但未选项只用于刻画另一面；条件项必须写明阶段或情境；排除项不得出现。不得因用户选择一个答案就把所有章节写成同一种特点。
9. 正文保持纯文本，另用 `emphasis_spans` 标出重点断句。完整人生主线3—4句、当前问题2—3句、每个领域1—2句，每段最多一句；只能使用Core指定的重点判断。
10. 生成 `schema_version=1.3.0` 的 `report-draft.json` 后运行：

```bash
python internal/rensheng-youji-report-writer/scripts/validate_report_draft.py \
  work/report-draft.json --brief work/report-content-brief.json
```

写作层只负责组织人物材料，不负责最后中文润色。不得用固定“好处—代价—建议”模板，不显示校准结果，不新增Core没有授权的行业、岗位、经历、关系状态或年份。
