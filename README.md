# 人生有迹免费卡片 Skill

“人生有迹”免费版会在用户自己的运行环境中完成确定性排盘、人生主线分析和PNG制图，不需要验证码，也不会调用人生有迹云端接口。

## 免费卡片包含

1. 出生配置
2. 初始天赋
3. 核心配置
4. 主线任务
5. 20年连续人生K线
6. 当前课题

人生主线是免费版的核心内容；人生K线用于把原局、大运和流年放在连续轨迹中观察。当前年份用金色高亮，单年影线体现年内变化幅度，不绘制年度收盘连线。

## 1.1版改进

- 内置中国省、市、县区三级出生地数据，用户通常只需输入常用地名，不再填写经纬度和时区；重名地点才需要补充省或地级市。
- 核心配置分为稳定能力和时柱落点，主线任务同时结合二者，避免时柱改变后内容仍完全相同。
- 当前课题不再由年龄直接决定，而是结合核心配置、主线任务、当前大运、近三年和K线阶段，从具体生活矛盾中选择。
- 全部规则仍在用户本地确定性运行，不增加验证码、云端接口或模型调用成本。

## 使用方法

安装或添加本 Skill 后，只需发送：

> 请用“人生有迹免费卡片”帮我生成卡片。

AI 会一次询问出生年月日时、出生城市、性别和时间口径；姓名可以不填。成功后返回一张 1242×1660 PNG。

如果当前AI不能安装或运行Skill，也可以直接使用：

> [人生有迹免费网页版](https://rensheng-youji-web.bobbybluemoment.workers.dev)

网页版不需要登录或验证码，排盘与制图同样在浏览器中完成。

## 运行要求

- Python 3.11 或更高版本
- 可以读取 Skill 文件并运行本地 Python 的 AI 客户端
- 首次运行可由 AI 自动安装 `requirements.txt` 中的两个依赖
