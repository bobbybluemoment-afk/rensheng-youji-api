# 人生有迹完整报告框架

## 取材原则

完整报告只消费已经校验的 `analysis_bundle`，不重新推命。每个章节先从指定 Core 字段选择结论，再用普通中文压缩和组织。

重要结论按以下关系组织，但不要把这五项机械写成每段相同的小标题：

1. 现实中可能怎样表现；
2. 这种方式依靠什么形成；
3. 它怎样影响行为、选择和已经出现的经历；
4. 当前大运与近年怎样把问题推到现在；
5. 什么现实条件改变后，可以出现另一种表现。

已被校准支持的结论优先；未验证但有多处证据的结论保留“可能”；社会常见路径只能帮助选择例子，不能写成命盘已经算中的经历。

## 用户关注方向的边界

用户选择事业、感情、财务或家庭，只表示当前最想优先理解的问题，不代表整个人生都围绕该领域展开。

- `life_theme` 必须从完整原局、根苗花果、家庭教育、资源、事业、财富、关系、身心与长期时运综合生成；
- `capabilities_resources` 与 `formation` 保持全景视角，不围绕用户问题筛选证据；
- 用户关注方向只重点进入 `current_situation`、`direct_answer`、`stage_story.present_task`、`stage_story.next_direction`、逐年回应和行动优先级；
- 六个领域保持相同篇幅范围和全盘基础判断，不能因为用户选择感情就把事业、财务和家庭写成感情的附属解释，也不能因为用户询问某类副业就让事业、财务、家庭反复围绕该副业；
- 从当前问题提取1—4个具体关键词，在完整主线、能力形成和六领域正文中每个最多出现两次；
- 校准题至少覆盖四个领域，同一领域最多两题。

正文只写现实语言。日主、十神、天干地支、身强身弱、透干、根苗花果等只能存在于内部审计，不得直接进入PDF正文。行动建议以 `generated_on` 为准，不能把过去的年份写成用户现在仍应开始做的事。

## 开篇顺序

### 1｜能力与可用资源

主要读取：

- `complete_self_portrait`；
- `resource_relationship`；
- `natal_portrait`；
- `reality_domains.learning/career/growth`。

先说明用户已经形成的能力、获得支持的方式、可调用的制度/人际/技能资源，以及这些资源在哪些条件下更容易真正留下。不要先从缺点或困境写起。

### 2｜这些方式怎样形成

主要读取：

- `family_system`；
- `root_seed_flower_fruit_map`；
- `social_context_model`；
- `life_stages`。

把家庭支持与要求、教育训练、城市和时代条件、早期承担的角色串成形成过程。不能把所有问题归因于父母，也不能把社会常见路径冒充命理结论。

### 3｜当前阶段与用户问题

主要读取：

- `luck_cycle_themes`；
- `annual_theme_activation`；
- `domain_connections`；
- `turning_points`；
- `calibration_state`。

写清上一阶段留下什么、近几年怎样发展、现在最具体的矛盾，以及未来两三年已有条件可能怎样继续。直接回答用户的问题，不只给泛化建议。

## 六个领域

固定顺序：

1. 性格与内在成长：`complete_self_portrait`、`reality_domains.growth`；
2. 恋爱与伴侣：`relationship_system`、`partner_profiles`、`interaction_dynamics`；
3. 事业发展：`reality_domains.career/learning`、`environment_and_mobility`、`resource_relationship`；
4. 财务与资源：`reality_domains.wealth`、`resource_relationship`、相关 `domain_connections`；
5. 身体与情绪：`reality_domains.health`、压力恢复、时间精力资源和 `safety_boundaries`；
6. 家庭与成长环境：`family_system`、`reality_domains.family`、相关 `domain_connections`。

每个领域写成2—4个连贯自然段。覆盖特征、行为、形成、经历、现实条件、重复挑战、当前变化和应对方式，但这些只作为内部覆盖检查，不显示成固定小标题。`audit` 保留置信度、来源和待验证内容；“现实落点、核对点、判断等级、校准后的现实线索”等内部词不进入用户可见正文。

每章70%—80%使用该领域专属判断，人生主线和跨领域内容只占20%—30%。同一Core判断最多进入两个领域；移除主线句后，该章仍须独立说明人物在这个领域中的样子。家庭不得默认照搬事业中的协调、联系或收尾角色；身体与情绪不得只写工作负担。

六个领域分别覆盖：

- 性格与内在成长：怎样做决定；习惯如何形成；过去容易反复遇到什么；当前怎样变化与调整。
- 恋爱与伴侣：容易被什么特质吸引；怎样建立和维持关系；可能经历的互动与冲突；当前怎样处理。
- 事业发展：能力、性格、教育与家庭资源怎样影响工作；更匹配的行业机制、单位、岗位和工作环境；反复出现的问题；阶段变化与应对。
- 财务与资源：资源起点与金钱态度；主要和次要收入来源；积累方式与实际损耗；当前变化与应对。
- 身体与情绪：压力来源与可观察信号；应对和恢复方式；容易形成的生活循环；当前怎样照顾自己。
- 家庭与成长环境：家庭氛围和资源；期待、分工、个人角色与边界；反复问题；当前变化与处理方式。

## 具体判断写法

具体感来自“写清特征、行为、经历、现实环境、挑战和变化”，不是把“可能”删掉，也不是编造唯一事件。完整遵守 `reality-anchor-language.md` 的名词精度规则。

- 性格写习惯和处理顺序：怎样开始任务、怎样搜集信息、怎样回应催促或质疑、压力后怎样恢复。不能只写稳重、自律、有责任感。
- 事业先写最匹配的工作机制，只保留一个优先方向；证据接近时最多增加一个近邻方向。机制确实指向规则、资质和长期积累时，可以写大型国企、事业单位、大型制造集团；指向高信息密度、快速反馈和产品转化时，可以写互联网大厂、成熟科技公司及相应岗位。名词必须进入来源审计，不能当固定词库套用。
- 财务区分主要来源、第二来源、不稳定来源、容易漏财的情境与适合的留存方式，例如工资、专业溢价、项目奖金、提成、合作分成、家庭支持或资产收益；不保证收入结果。
- 关系把吸引与摩擦落到见面频率、回复、城市选择、金钱安排、见父母或未来计划；不推断具体对象职业与身份。
- 家庭与教育区分谁更像支持来源、谁更像规则或期待来源、用户常承担的家庭角色、边界处理和学习路径候选。无法判断具体父母时给出两个角色候选，不机械指定父亲或母亲。
- 身体与情绪只写压力信号、恢复条件和生活节奏，不从五行直接推断器官疾病。

每个重要判断和现实名词内部保留来源、替代解释和待验证内容。若校准选择或用户补充事实支持其中一项，可以调整结论选择和确定程度，但不得显示用户答案、校准摘要或“校准确认”。

## 关系写法

分别说明：

- 用户在关系中的需要、表达、冲突和修复方式；
- 容易被什么特质吸引；
- 什么特质更适合长期相处；
- 哪些组合可能强吸引但摩擦较高；
- 工作、城市、家庭与财务怎样影响关系。

单人命盘不能描述某个具体对象，也不能判断两个人一定合适或不合适。

## 时间写法

- 大运负责阶段主题，流年负责触发和执行；
- 先概括已经经历和未来较长的大运阶段，再展开 Core 已提供的连续年度范围；
- 每年只保留主题、从上一年带入什么、一个现实载体、给下一年留下什么和置信度；
- 不把“变化大”等同于坏，不把“稳定”等同于好；
- 不把毕业、结婚、买房、生育等社会节点写成必然事件。

逐年观察适合用紧凑表格呈现，避免二十年各写一大段导致报告失控。

## 篇幅与固定版面

- Markdown正文建议约5200—7600个汉字；
- 正式PDF固定10页；未完成五条校准时不生成正式PDF；
- 开篇能力、形成过程与当前阶段合计约25%；
- 六个领域合计约35%；
- 时间、行动、验证与作者信息合计约25%；
- 用户问题在第4页、逐年提醒和行动建议中优先回应；六领域基础篇幅保持完整、均衡，不因关注方向改变。

完整人生主线写3—4个自然段、500—700个汉字；每个领域写3—4个自然段、500—700个汉字。每段至少对应两个实体化Core判断，写成同一个人物的连续侧面。不设置逐段固定字数，也不显示固定内容槽位标题。逐年观察每年压缩成自然的连续短叙述；普通年份不强行虚构事件，重点年才增加明确载体，禁止让PDF渲染器截断超长文字。

固定页序如下：

1. 固定品牌封面、Logo、报告介绍与末页联系方式提示；
2. 同一份校准后 Core 生成的新版1242×1660人生卡片；
3. 完整人生主线、能力、可用资源与形成过程；
4. 当前阶段、用户问题与前后阶段连续性；
5. 性格与内在成长、恋爱与伴侣；
6. 事业发展、财务与资源；
7. 身体与情绪、家庭与成长环境；
8. 前10年逐年观察；
9. 后10年逐年观察；
10. 行动建议、仍需验证、作者、GitHub、免费网页、微信二维码与阅读边界。

PDF使用米白底、深青绿色标题、金色重点与粉色关系提示。正文固定使用仓库内置霞鹜文楷，标题使用仓库内置 Noto Sans CJK；正文统一左对齐、不做首行缩进，不根据单页字数任意改变字号。微信图片必须读取仓库本地 `assets/wechat-contact.jpg` 并实际嵌入，不能只打印图片网址。

重点展示遵循“宁可少，不破坏正文”：完整人生主线通常2条，当前问题通常1条，每个领域最多1条，没有合适判断时允许为空。重点句必须是16—70字、带句末标点的完整判断，由Core指定判断支持；不能突出证据、例子、限制语、连接语或行动清单。PDF将重点句独立成行并使用深青色，不在长段落内部逐字切换字体；视觉增强失败时自动使用统一正文的稳定模式。

报告中的明显关系进入或发展机会年份必须与卡片桃花高亮年份完全一致。卡片桃花留白时，报告只能写社交、表达或关系观察条件，不能升级成明确的关系机会年份。

## 需要继续验证

只列真正会改变结论的2—5项，例如出生时间边界、家庭角色未核对、现实路径存在两种解释、未来年份依赖尚未出现的工作或关系条件。不得把所有章节统一降格为“仅供参考”。
