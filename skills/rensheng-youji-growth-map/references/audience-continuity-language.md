# 用户画像、时间连续性与白话表达

## 用户画像的正确用途

主要用户通常为20—40岁，至少接受过普通高中或本科教育，并活跃于小红书、微信等平台。该画像只用于选择容易理解的表达和较常见的现实问题，不是命盘证据。

- 20—24岁可优先询问毕业、第一份工作、考试、城市选择与经济独立。
- 25—29岁可优先询问换工作、工资与发展、考证转行、稳定关系与父母期待。
- 30—34岁可优先询问晋升、专业或管理路线、住房、长期关系与家庭分工。
- 35—40岁可优先询问职业上限、收入来源、合作责任与父母照护。

不得直接假定用户有工作、伴侣、房贷、孩子或特定家庭经历。用户一旦提供真实经历，立即以真实经历为准；画像只在多个候选同样有依据时帮助排序。

出生城市不是性格证据，但可以帮助理解现实条件：当地教育与产业结构、是否常见跨省求学、家庭对体制与稳定工作的重视、进入大城市的成本。只能用于生成和排序候选，不能写成地域刻板印象。

学历尚未确认时，可以由印、官杀、食伤等完整关系、相关大运与常见教育年龄形成“学习路径候选”，但首轮优先判断路径特征，不轻易精确断一本、硕士或名校。只有盘面多处支持且用户年龄足以核对时，才可问“学历大概率不低于本科”“有过考研、考证或转专业”等高指向性事实。

事业报告可以讨论感情、家庭或财务，但只在它们确实影响用户的工作选择时展开。例如伴侣所在城市影响是否换工作，父母期待影响是否考公，家庭支出影响是否接受收入波动。

## 运势必须连续解释

人的经历通常经过“条件形成—尝试—关系或环境变化—结果出现”，很少在两个年份之间毫无原因地翻转。时间分析固定遵守：

1. 原局说明反复使用的办法和主要矛盾。
2. 上一大运说明进入当前阶段前已经积累的能力、关系、资源和责任。
3. 当前大运说明这些条件怎样被继续使用、放大、调整或限制。
4. 近三年说明问题如何逐步形成，不把每年判成独立的好坏。
5. 未来两三年说明已有条件可能怎样继续发展，不凭空预设事件。

合冲刑害只解释变化怎样发生。例如某种关系被打断、原有支持换了来源、责任变得公开；不能只因出现冲刑就写“突然变差”。同一影响不要既当作年度方向，又重复当作额外风险。

用户举出的“前一年学习、下一年认识人、再下一年获得结果”等例子只说明连续性的精神，绝不能写成任何具体命盘的事实。

## 人生节点怎样进入判断

年龄和社会时间表用于缩小事件范围：18岁前后常见升学，22—25岁常见毕业与就业，之后常见换工作、长期关系、迁居和经济独立。但每个节点只有在原局、大运、流年或用户背景提供额外支持时才可进入事实校准。

具体流程：

1. 先根据出生年份列出用户实际年龄与当年社会阶段。
2. 再看大运是否改变支撑、规则、流动、收入、关系或居住主题。
3. 再看流年是否触发原局与大运已有关系。
4. 最后提出事件类别与时间窗口，例如“2020—2021年前后更像从学校进入工作、搬离原居住地或第一次经济独立中的一种”，不强行指定唯一事件。

用户确认事件后，再沿着前因、发生、结果和后续影响写入报告，使年份彼此连续。

## 把黑话改成日常语言

报告优先使用具体名词和动作。每个抽象判断至少配一个可观察表现。

| 避免 | 改写方向 |
|---|---|
| 卡住、卡点 | 一直难以决定；同一个问题反复出现 |
| 换轨、切换赛道 | 换工作、转行、调整岗位或改变发展方向 |
| 兑现能力、兑现价值 | 能力是否带来职位、收入、作品或更多选择 |
| 承接机会、承接资源 | 拿到机会后是否有时间、人手、预算和能力把事情做完 |
| 抓手 | 第一步具体做什么 |
| 底层逻辑 | 为什么会这样；真正起作用的原因 |
| 资源整合 | 具体说明是在协调人、信息、预算、客户还是渠道 |
| 稳定输出 | 按时完成什么工作、作品或结果 |

“成长、价值、节奏、边界、选择空间”不是完全禁用，但必须说明现实含义。不能只写“找到自己的节奏”，要写成“决定一周能承担多少工作、什么任务需要拒绝”。

## 具体但不武断

- 可以写：“你现在更可能在考虑，这份工作是否值得继续做。”
- 可以写：“可能表现为事情越做越多，但工资、职位或学到的东西没有一起增加。”
- 不可写：“你今年一定会离职。”
- 不可写：“所有问题都来自原生家庭。”

具体感来自说清楚用户正在权衡的两个现实选项，而不是提高确定语气。付费报告必须继续用现实经历校准，并把未获得验证的判断标为待验证。
