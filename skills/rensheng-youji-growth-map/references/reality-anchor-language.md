# 事实型判断与现实名词落点

本文件约束完整报告的用户可见语言。目标不是把语气写得武断，而是让每个判断有明确对象、现实表现和可核对边界。

## 一段只完成一个判断

六个领域统一使用四步：

1. `main_verdict`：先下一个主判断。只说最有区分度的一件事，不并列三种性格、四类岗位或多条关系路线。
2. `reality_anchor`：把主判断落到现实名词。先写工作机制或互动机制，再写被证据支持的组织、任务、收入形式或生活安排。
3. `pattern_and_cost`：说明这个判断在日常怎样发生，以及它带来的结果或代价。必须包含行为顺序、选择条件、重复情境或可观察结果，不能继续换词描述性格。
4. `verification_point`：只留一个真正能改变或收窄结论的核对点。它不是行动建议，也不是另一段泛泛总结。

主判断最多保留一个“可能、倾向、容易、更像、适合”等条件词。条件词用于标记证据边界，不能每句话都弱化。

## 名词精度由证据决定

`audit.anchor_precision` 只有三种：

- `user_confirmed`：用户明确提供了职业、组织、关系状态、家庭任务或收入事实。可以直接使用对应名词，`user_facts` 必须记录原始事实。
- `multi_method`：至少两个相对独立的 Core 视角指向同一现实机制。可以写组织类别、岗位族、任务类型或收入形式；每个名词在 `reality_anchor_sources` 中至少有两个来源。
- `category_only`：证据只支持较宽类别。仍要给出可核对的现实载体，但 `verification_point` 必须明确目前不足以缩小到唯一行业、岗位、对象身份或家庭经历。

“具体”不等于猜唯一答案。没有用户事实时，不得把“大型组织”直接收窄为用户已经在某家大厂或国企工作；可以写“优先看大型国企或成熟科技公司”，并交代共同机制是什么。

## 各领域可以使用的名词

### 性格与内在成长

优先写行为载体：任务清单、交付复核、信息搜集、反复检查、延迟表达、独处恢复。不要只写“谨慎、负责、想得多”。

### 恋爱与伴侣

优先写互动与现实安排：见面频率、回复节奏、异地安排、城市选择、见父母、金钱安排、未来计划。可以写被哪种做事方式吸引，但没有用户确认时，不得猜对象的具体职业、籍贯或家庭资产。

### 事业发展

先写工作机制，再写名词：

- 规则、资质、长期积累明显：可落到大型国企、事业单位、大型制造集团及相应专业岗位；
- 信息密度高、快速反馈、产品转化、跨团队协作明显：可落到互联网大厂、成熟科技公司、产品运营、数据分析、项目管理；
- 风险识别、规则执行、材料审查明显：可落到金融机构、审计风控、合规、研究分析。

以上只是名词类型示例，不能当作固定词库轮流套用。只有 Core 的组织环境、任务方式、能力形成和阶段主题至少两个视角共同支持时才可使用。每段只保留一个优先方向；若两个方向证据非常接近，可并列一个近邻方向，并说明二者共同的工作机制。不要列出2—4个互不相干的行业和岗位。

### 财务与资源

写收入和漏财的实际形式：固定工资、年度绩效、项目奖金、销售提成、咨询费、内容收入、租金或资产收入、人情垫付、口头分成。不能只写“正财、偏财、专业变现、资源积累”。

### 身体与情绪

只写可观察的压力节奏：睡前复盘、连续加班、信息过载、颈肩紧张、三餐推迟、独处恢复。不得诊断疾病或器官问题；持续症状应建议正规医疗评估。

### 家庭与成长环境

写家庭事务的载体：学费与证书费用、住房安排、工作信息、长辈照护、家庭分工、经济支持。没有用户明确事实时，不得猜父母的具体职业、婚姻经历或资产数额。

## 校准答案必须进入判断

A/B/C 被用户选择的 `selected_text` 是现实证据，不只是提高置信度。相关领域应把它转成主判断、现实落点或表现与代价，并在 `audit.user_facts` 或对应来源中保留。用户补充的事实优先于通用社会先验；D 只能表示未知，不能反向解释成“不存在”。

## 年度语言

逐年字段使用 `real_world_signal`，不再统一写“可能表现”。现实载体可以是项目交付、岗位调整、考试证书、搬家、见父母、合同签订、复购客户、回款或家庭分工。普通年份只写一个延续载体，重点年可以写得更明确；不能为了每年都具体而虚构事件。`signal_terms` 必须原样出现在 `real_world_signal` 中。

## 反例与改写

- 反例：“你适合有门槛的大型组织，也可能从事技术、管理、表达或创意工作。”
- 改写：“你适合规则和晋升标准明确的组织，优先看大型国企或成熟科技公司的项目管理；你的优势是把跨部门任务盯到交付，不是泛泛协调。”

- 反例：“你的财运来自专业能力，也可能有副业、合作或投资收入。”
- 改写：“收入的主轴是固定工资和年度绩效；项目奖金可以增加上限，口头合作分成反而最容易拖延回款。”

- 反例：“你慢热、重实际，容易被优秀的人吸引。”
- 改写：“你会先看对方能否稳定见面、按约回复并讨论城市安排；做事利落会让你心动，替你作决定则会很快形成摩擦。”
