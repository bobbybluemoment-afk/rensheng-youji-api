# 事实型判断与现实名词

本文件约束完整报告的判断精度。目标是让用户读到具体的性格、行为、经历和现实方向，同时不把证据较弱的候选写成既成事实。

## 从机制写到生活

每个领域先确定最有区分度的整体特征，再分别写行为模式、形成经历、现实环境、重复问题、阶段变化和应对。不要把所有内容压缩成一句“主判断”，也不要统一套用“好处—代价”。

条件词用于标记证据边界。有两处以上独立证据时可以直接判断；只有单一线索时使用“可能、例如、更容易”等词，但同一段不要反复弱化。

## 名词精度由证据决定

`audit.anchor_precision` 只有三种：

- `user_confirmed`：用户明确提供职业、组织、关系状态、家庭任务或收入事实。可以直接使用对应名词，`user_facts` 必须记录原始事实。
- `multi_method`：至少两个相对独立的 Core 视角指向同一现实机制。可以写组织类别、岗位族、任务类型或收入形式；每个名词在 `reality_anchor_sources` 中至少有两个来源。
- `category_only`：证据只支持较宽类别。正文可以说明共同机制，但不能收窄到唯一行业、岗位、对象或经历；具体缺口写入 `audit.needs_validation` 和报告末页“仍需验证”。

“具体”不等于猜唯一答案。没有用户事实时，不得写成用户已经在某家大厂或国企工作；可以写“更适合制度和分工成熟的单位，例如大型国企或成熟科技公司”，前提是 Core 至少两个视角支持共同的工作机制。

## 各领域可以使用的现实内容

### 性格与内在成长

写任务开始方式、信息搜集、决定顺序、交付复核、回应催促、表达不满和独处恢复。结合家庭、教育与既往经历说明这些习惯怎样形成，以及它们怎样反复影响选择。不要只写“谨慎、负责、想得多”。

### 恋爱与伴侣

写容易被什么做事方式吸引、建立信任的节奏、见面和回复习惯、城市选择、金钱安排、未来计划、冲突与修复。没有用户确认时，不得猜对象的具体职业、籍贯或家庭资产。

### 事业发展

先分别判断工作方式、组织属性、行业、职能岗位、处理对象和发展方式，再组合现实方向。候选应覆盖但不限于公务员、事业单位、国企、民企、外企、专业机构、初创公司、自由职业、个体经营、创业、主业加副业；岗位可以继续扩展到人力、行政、财务、审计、税务、法务、合规、IT技术、产品、项目、运营、生产质量、供应链、市场、销售、教育内容、设计、医疗助人和经营管理。

这些名词都只是开放候选，不是职业对照表。不得用官印直接等同体制内、食伤直接等同自由职业、财星直接等同财务或销售。还要说明用户在相应环境里怎样工作、怎样晋升、容易遇到什么问题，以及当前阶段正在发生什么变化。最终正文只选证据最强的一至三个例子，不列职业大全。

### 财务与资源

写家庭和早期资源的可能起点、金钱态度、主要收入、第二收入、不稳定收入、积累方式和实际损耗。例如固定工资、年度绩效、项目奖金、销售提成、咨询费、内容收入、租金、家庭支持、人情垫付和口头分成。不能只写“专业变现、资源积累、财务结构稳定”。

### 身体与情绪

写压力从哪里开始、身体和情绪最先出现什么信号、用户怎样压住或恢复、哪些生活节奏会反复消耗。不得诊断疾病或器官问题；持续症状应建议正规医疗评估。

### 家庭与成长环境

写家庭重视什么、提供什么资源、形成什么要求；用户承担什么角色，怎样处理责任和个人边界。现实载体包括学费与证书费用、住房安排、工作信息、长辈照护、家庭分工和经济支持。没有用户事实时不得猜父母具体职业、婚姻经历或资产数额。

## 校准答案怎样影响报告

A/B/C 的选择只用于改变 Core 候选状态、排序和措辞强弱。不得把 `selected_text`、校准摘要、“校准确认”或“符合判断”写入正文。用户主动补充的事实可以进入相应领域的内部来源记录。D只表示未知，不能反向解释成“不存在”。

## 年度语言

逐年字段使用 `real_world_signal`，现实载体可以是项目交付、岗位调整、考试证书、搬家、见父母、合同签订、复购客户、回款或家庭分工。普通年份只写一个延续载体，重点年可以写得更明确；不能为了每年都具体而虚构事件。

## 反例与改写

- 生硬：“你适合在单位或平台内做专业，靠职级与项目积累，而不是从零单干。”
- 自然：“你适合在制度和分工较成熟的单位任职，通过持续负责重要项目、建立专业口碑和承担更大职责逐步晋升。相比从零创业，这条路更能发挥你愿意长期积累的特点。”

- 生硬：“你的财运来自专业能力，也可能有副业、合作或投资收入。”
- 自然：“收入的主轴是固定工资和年度绩效，项目奖金可以提高上限。合作收入能否留下，关键在于分工、报价和结算日期是否提前写清。”

- 生硬：“你慢热、重实际，容易被优秀的人吸引。”
- 自然：“你会先观察对方能否稳定见面、按约回复并认真讨论城市安排。做事利落会让你产生好感，习惯替你作决定则容易形成摩擦。”
