# 分析方法

## 基本立场

把十神视为词汇，把原局视为一句由多种关系组成的话。八字不存在脱离具体组合的固定解释；分析目标是理解一个人反复使用的生存方式、这种方式依靠什么成立，以及它怎样同时成为能力和限制。

- 不用单个十神直接贴性格、职业、亲属或吉凶标签。
- 不用五行数量、旺衰分数或固定用神代替对原局关系的理解。
- 不把合解释为吉、冲刑害解释为凶；只描述它们怎样改变相关符号的关系。
- 不因用户经历而倒推、篡改排盘事实；信息不足时保留两种可能，并说明需要验证什么。
- 先描述人，再讨论事业事项。深度报告可以保留多条候选读法，但必须区分主结论、次要解释与待验证假设；用户画像只能帮助选择现实例子，不能替代盘面和经历。

## 解释顺序

按以下优先级理解原局，不做数字评分：

1. 十神、透干、藏干以及每个天干是否有根。
2. 年月日时形成的根苗花果，以及四者能否相互承接。
3. 最关键的天干地支关系：合、冲、刑、害及由此形成的势头。
4. 月令、季节、五行生克、格局、旺衰喜忌、调候、象法、六亲、星宫同参和古籍脉络作为背景、补充与复核，不作为先验答案。

日柱固定选手类型只是低门槛入口。不得为了证明选手类型而选择性解释其他三柱。

## 十神如何使用

下表只提供组词时的起点，不是固定字典。同一十神在不同位置、根气和组合中可以表现出不同甚至相反的现实样貌。

| 十神 | 优先理解的关系 |
|---|---|
| 正官 | 中心、规则、秩序、协调和使用人 |
| 七杀 | 具体执行、高压环境、技术专精、效率要求 |
| 正印 | 授权、资格、认可、主流知识、受到庇护 |
| 偏印 | 非主流知识、边缘位置、地方性技艺、与当下环境错位 |
| 食神 | 从某个网络获得供养、余裕、福利和自我实现空间 |
| 伤官 | 离开中心、超出本分、流动、解构、另找路径 |
| 正财 | 规则能够控制和结算的资源、稳定收入、常规交易 |
| 偏财 | 家族或群体共有资源、外部交易、不完全受规则控制的资源 |
| 比肩 | 与自己处于相近位置的人、自立、并肩、直接依靠自身能力 |
| 劫财 | 同类之间既合作又分配资源，不完全同路的同行者 |

不要把边界写死。例如七杀集中时可能出现伤官式的不安分与越界；伤官把一件事做到极致，也可能形成官杀式的组织和控制。解释这种变化必须指出原局中哪些关系促成了它。

## 透干、藏干与根

先看天干。透出的十神是较容易被外界看见的身份、做事方式、姿态或工具。

再检查每个天干在全部地支藏干中是否出现完全相同的天干：

- 有根：这个外显方式背后存在实际支撑，较容易稳定使用。
- 无根：这个方式虽然出现，却未必有稳定来源；可能是愿望、身份、证书、姿态、借来的位置或难以长期维持的做法。
- 藏干没有对应透干：把它视为背景条件或尚未直接表达的能力，不自动当成现实表现。

有根不等于好，无根不等于坏。羊刃、墓库只作为特殊联系，不能与最直接的根混同。出现多个根、天干地支相互呼应或关系汇聚时，可以说它形成了明显势头，但不要换算成分数。

## 根苗花果

根苗花果是一条有先后关系的生长链，也是一株植物在任何时刻同时具备的四种功能。年、月、日、时分别作为观察根、苗、花、果的入口，但不得固定翻译为父母、兄弟、配偶、子女，也不得只套童年、青年、中年、晚年。

- 根：从哪里获得养分、归属与立足点。可以是家庭、乡土、人、事件、技能、行业或群体。
- 苗：靠什么支撑自己，并怎样把根的资源输送和转化出来。常涉及技能、近层关系和可使用的外界支持。
- 花：选择让外界看见什么，以及借什么为结果做准备、证明或实现自己。
- 果：最终做出、留下和延续什么，包括作品、行动、关系结果或其他后天作为。

分析时依次回答：

1. 这个人靠什么扎根？
2. 他靠什么能力、关系或环境把资源接上来？
3. 他选择怎样表现自己？
4. 这种表现容易结出什么结果？

同时检查四者是否接得上：根能否输送到花，苗是否承担得住，花是否背离根，果是否依赖本人并不认同的支撑。不要把这些情况直接判断为好坏。

## 从原局提炼主要读法

### 第一步：写出外显内容

列出除日主外的透干十神，说明它们分别表现为何种方式。先组句，不谈职业和吉凶。

### 第二步：查根与底色

逐一说明哪些透干有根、哪些无根，以及每个地支承载了什么。重点寻找“外面看起来是甲，真正支撑它的是乙”的关系。

### 第三步：看相互关联

只选择真正改变整句含义的合、冲、刑、害与汇聚关系。说明谁支持谁、谁牵动谁、谁可能把谁推向第三方，不罗列全部术语。

### 第四步：串起根苗花果

把根的来源、苗的支撑、花的呈现与果的结果连成一条可理解的生活主线。若有断裂或反差，将其作为需要验证的候选，不直接下结论。

### 第五步：寻找反复使用的方式

从以下位置寻找一个人可能没有意识到、却反复依赖的生存方式：

- 外在表现与底下支撑不一致。
- 根苗花果之间难以承接。
- 某一种关系承担了过多功能，例如一直靠控制解决不安、靠流动逃离限制、靠照顾别人维持关系，或靠成果换取认可。
- 原局缺少某个符号时，只能在理解整句话之后，判断他为何围绕相关问题打转；不得直接从“缺什么”生成标准答案。

不要使用“无明重”“执念深”等评判。说明这套方式最初保护了什么、形成了什么能力，以及在什么情况下可能限制选择。

### 第六步：生成深度分析底稿

把原局分析整理为可校准的结构假设：

- 主结论：由多处盘面关系支持，最可能解释用户反复出现的事业选择。
- 次要解释：结构成立，但现实映射可能因行业、家庭、教育或组织环境而不同。
- 待验证假设：只有单一线索、依赖时柱或与用户经历存在分歧。
- 行动含义：说明在什么现实条件下可以扩大选择，不以“改正缺点”为目标。

推荐的白话结构：

> 你常用____来处理工作问题，真正支撑它的却是____。当____被当成唯一办法时，你更容易____；如果____条件成立，同一结构也可能表现为____。

不要机械填空。成文时使用自然、具体、可验证的语言，避免“能量场、命运齿轮、灵魂脚本”等自造术语。

## 分歧与复核

- 一个结构有两种合理现实映射时，优先选择能解释更多关系、需要更少额外假设的一种。
- 证据接近时保留两个候选，并用校准问题区分；用户没有提供足够经历时，不假装已经确认。
- 格局、旺衰喜忌、调候、象法、六亲与古籍可用于复核或补充。出现分歧时保留分歧，不机械平均。
- 大运流年用于在理解原局后修正和观察时间变化，不反过来替换原局主线。分析当前大运前，先说明上一大运留下的能力、资源、关系和责任；近三年与未来两三年按连续过程解释，不做精确事件承诺。

## 八字各方法怎样交叉验证

不同方法常在观察不同层面，不按“赞成票”简单累加：

- 十神、透藏与根苗花果：优先解释一个人如何获得支撑、怎样做事、展示什么并留下什么结果。
- 格局与月令：观察社会角色、制度位置和主要矛盾是否形成稳定组织，不把格局名称直接当职业。
- 旺衰与喜忌：观察某种方式是否有足够支撑、使用代价是否过高，不把强弱分数当人格分数。
- 调候：观察寒暖燥湿等整体条件及其生活取向，可辅助身体感受、环境和季节建议，不单独断疾病。
- 象法与干支关系：帮助形成场景、人物互动和事件方式，但必须回到完整结构与现实验证。
- 六亲方法：形成父母、伴侣和家庭角色候选；传统对应存在历史性别与家族制度背景，不能机械套用现代家庭。
- 神煞与特殊组合：只在与主结构和现实事件一致时点到为止，不承担核心结论。

若两个以上方法从不同角度指向同一现实机制，例如都指向“通过资格与成熟制度获得位置”，可以提高候选优先级；若只是重复同一基础关系，不算独立证据。

## 从八字走向现实推理

人首先是具体社会中的人。每个候选结论都可沿下列链条检查：

> 盘面关系 → 反复使用的行为 → 所处家庭、学校、城市或组织的反馈 → 现实事件 → 身体与情绪后果

例如早年大运持续引入高压执行，而原局支撑较弱，可形成“长期被要求完成超出年龄或能力的任务”的候选。若家庭权威强、学校竞争激烈、同类支持又弱，现实上可能进一步表现为家庭压力、人际排挤、校园欺负、害怕出错或长期紧张；这些结果必须分别核对，不能只凭“身弱杀旺”一次性全部判定。

社会现实推理可以使用：

- 年龄与当时教育制度形成的毕业、考试、就业常见窗口；
- 出生地与成长城市的教育资源、家庭观念、迁移成本和行业机会；
- 用户已确认的学历、家庭资源、职业、收入与关系状态；
- 中国就业中的考公考编、国企事业单位、互联网与民企、小城与大城市差异；
- 同一代人的经济环境、住房、婚育和照护压力。

必须在内部区分三类信息：`用户事实`、`社会条件推理`、`命盘候选`。成文时可以连成自然解释，但不能把社会常识伪装成命盘独有结论。

## 安全表达

- 不输出确定性医疗、法律、金融、死亡或灾祸判断。
- 不用“注定、必然、克、灾”等恐吓性语言获客。
- 不评判用户的选择，不把生活困境归咎于单个十神。
- 把结论写成可验证的倾向，并明确哪些内容仍需现实经历支持。
