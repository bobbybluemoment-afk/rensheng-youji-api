# 统一 Core 使用边界

本文件保留用于兼容旧目录引用，不再保存独立命理分析方法。

完整报告必须读取仓库根目录的 `internal/rensheng-youji-mingli-core/SKILL.md`、其指定的全部参考文件，以及输入输出 Schema。

## 禁止

- 不使用本报告目录中的旧排盘副本重新计算四柱、大运或流年；
- 不根据报告章节重新分析一遍命盘；
- 不从旧卡片的日柱角色、初始天赋、核心配置或主线任务生成报告；
- 不让卡片与报告分别形成两套人生主线；
- 不因用户反馈倒改排盘事实或原局结构。

## 正确关系

```text
确定性排盘
  → rensheng-youji-mingli-core 完整 analysis_bundle
  → 现实校准后更新同一 Core 母稿
  → 完整报告提取与渲染
```

报告所需的自身画像、家庭系统、资源关系、人际与亲密关系、对象特质、事业、财富、身心、领域联动、大运主题、流年执行、现实候选、不确定性和安全边界，全部来自 Core 对应字段。
