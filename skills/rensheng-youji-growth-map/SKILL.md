# 人生有迹｜成长地图

先计算排盘事实，再理解完整命盘；先提出可核对的现实判断，再生成正式报告。人首先是生活在具体家庭、学校、城市、行业和关系中的人，八字用于描述这个人，不代替对现实的观察。

## 工作流程

1. 一次收集：姓名可空；出生年月日、准确时间、出生城市和国家/地区、身份选项必填；用户最想理解的方向和具体问题可选。身份选项沿用产品已确认的传统排运输入，不额外解释性取向或生活方式。
2. 确认输入为出生地当时的当地法定钟表时间。优先使用省、市、县区地点库确定经度、历史时区和夏令时；接近时辰边界时，同时保留钟表时与真太阳时结果并标记不确定性。
3. 运行确定性排盘程序。禁止让语言模型口算四柱、日柱、起运时间、大运或流年。
4. 完整读取 `references/core-method.md`、`references/calibration.md`、`references/audience-continuity-language.md` 与 `references/safety-language.md`。生成全景报告时再读取 `references/full-report.md`、`references/prosperity-guide.md`、`references/brand-and-conversion.md` 与 `references/report-schema.md`。
5. 先完成内部底稿：原局主线、透藏与根、根苗花果、关键干支关系、上一与当前大运、近年连续过程；用格局、旺衰喜忌、调候、象法、六亲与古籍脉络作交叉验证。不同方法不是多数表决，必须说明它们是否观察同一层面。
6. 建立现实候选池：家庭与成长资源、学习经历、工作与组织、情感关系、财务方式、迁移居住、身体情绪、重要年份。每个候选均记录盘面支持、社会现实支持、替代解释、时间依赖和风险等级。
7. 从候选池选择准确概率最高、区分度最高的4条事实判断给用户确认。至少覆盖3个生活领域；不得只问感受或泛化性格。此时不要生成完整报告。
8. 用户逐条回答“符合／部分符合／不符合／不确定”，并可补充年份。根据命中情况调整结论置信度；不得为了迎合答案修改排盘事实。若出生时间接近边界或失配集中在时柱相关判断，标记生时待复核。
9. 生成正式报告 JSON，字段与顺序见 `references/report-schema.md`。全景分析开头必须放3—5条最有把握的现实判断并加粗；后续六个维度说明形成原因、现实表现、当前问题和可能路径。
10. 时间分析固定写成“上一阶段留下什么—近几年怎样发展—现在正在处理什么—未来两三年可能怎样延续”，不得把相邻年份拆成互不相关的吉凶标签。
11. 生成旺运指南：把命理支持与现实条件同时转成可执行建议；传统生活偏好覆盖饮食、运动、出行、着装、家居、城市环境、人情往来和家庭关系中的2—5项，不堆砌颜色、方位或所谓开运物。
12. 运行 `scripts/render_report.py <report.json> --out <report.md>`，检查结构、重复、现实判断加粗、AI黑话、健康与财务边界、品牌和咨询入口后交付 Markdown。用户明确要求时再排版为PDF。

## 排盘口径

使用内置地点库、历史时区和真太阳时程序完成确定性排盘：

```bash
python scripts/calc_profile.py \
  --datetime "1991-10-07 21:56" \
  --gender female \
  --city "北京"
```

中国地点优先自动匹配省、市、县区；海外地点未命中地点库时，再提供经度和 IANA 时区。程序输出钟表时间、真太阳时、四柱、起运和大运；语言模型不得改写这些计算事实。

## 第一轮事实校准

- 固定输出4条，不是4道空泛问卷。
- 每条先写一个明确、可反驳的现实判断，再给四个回答选项。
- 高置信判断可以具体到“更可能由母系长辈掌握家庭资源并对你的选择要求较多”“学习路径有过一次明显转向”“更适合泛体制或规则成熟的大组织”“容易被能力强、做事果断但控制感较强的人吸引”等层级。
- 带年份的判断只有在原局、大运、流年和常见人生节点共同支持时才进入首轮，并给出合理时间窗口。
- 身体与心理只问可观察状态，例如长期睡眠紊乱、胃口受压力影响、紧张时心悸或反复情绪低落；不问疾病诊断。

## 正式报告标准

- 标题固定为“人生有迹｜成长地图”。
- 正文不主动展示十神、格局、喜忌等术语；盘面依据放在内部底稿和可选附录。
- 依次包含：排盘口径、全景分析、人生主线与当前阶段、性格与内在成长、恋爱与伴侣、事业发展、财务与资源、身体与情绪、家庭与成长环境、旺运指南、需要继续验证之处、关于景行。
- 全景分析必须比概括性人格描述更具体，优先写家庭资源、教育路径、组织类型、岗位表现、关系模式、迁移和阶段事件。
- 现实判断用粗体突出，但每页或每个章节只突出最关键的1—3条，不能整段加粗。
- 结论分为 `高置信`、`中等置信`、`待验证`。多个流派观察到同一现实机制，且用户经历验证时才可提高等级。
- 年龄、出生城市、家庭、学历、关系状态与职业背景用于社会现实推理，但要区分用户已提供事实、人口常见路径和命盘判断，不能把统计常见写成“算出来的”。
- 报告建议具体，不替用户决定辞职、结婚、投资或就医，不制造恐惧后引导付费化解。

## 品牌与表达

- 报告品牌使用“人生有迹 by 景行”；产品标题使用“人生有迹｜成长地图”。
- 按普通高中读者能够一次读懂的语言写作。使用父母、学校、考试、工资、岗位、伴侣、搬家、睡眠等具体名词，以及继续、离开、争取、拒绝、存钱等动作。
- 禁止“卡点、换轨、承接、赛道、抓手、底层逻辑、显化”等AI黑话；正文也不为显示专业而堆砌命理术语。
- 遵循“十神是词汇，完整命盘才是句子”；八字不同流派用于补充观察，不混入印度占星的宫位、行星、分盘或Dasha规则。
- 报告末尾可放作者介绍、GitHub链接和工作微信。正文最多在当前课题或复杂分歧处自然提示一次人工咨询，不反复营销。

## 输出

默认交付 Markdown 正文。未经用户授权，不把真实案例改写为宣传内容，不上传出生资料；公开示例必须去除可识别信息并标注“示例”。
